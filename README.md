# 日语口语闪卡

按场景整理日语高频口语对话，自动生成闪卡学习。

## 功能

- **场景管理**：创建多个口语场景（餐厅、购物、面试等）
- **批量导入**：在文本框中按行粘贴日语对话与中文翻译
- **自动解析**：支持 Tab / `|` / `：` 分隔，或日语/中文交替行
- **闪卡学习**：正面显示中文释义，点击翻转查看日语原文
- **本地存储**：数据保存在浏览器，无需联网
- **神经语音朗读**：开发/预览模式下使用 Microsoft `ja-JP-NanamiNeural` 日语神经语音（需联网）；纯静态部署时回退为浏览器系统语音

## 输入格式示例

```
いらっしゃいませ。	欢迎光临。
メニューをください。	请给我菜单。

或：

いらっしゃいませ。
欢迎光临。
```

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可使用。

## 快捷键（学习模式）

- `空格` / `Enter`：翻转闪卡
- `←` `→`：上一张 / 下一张
- `R`：重新朗读当前日语（日语面）
- 翻转至日语面后自动朗读（可通过「🔊 朗读」开关）
